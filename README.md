# File taker aparter

Basically, just run take_apart_files.py to take a file apart and throw the remains into a folder, then run put_files_back_together.py to take all the pieces and put them back together. Just make sure all the files are in one folder with nothing else in it. The files don't work or do anything when they're ripped up and scattered in a folder, they're just smaller and easier to manage/yeet across the internet. You don't need any external modules, just python. If you don't have python, that's your problem.
